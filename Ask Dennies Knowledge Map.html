Replay a question

Each dot is one real passage from the index. The layout comes from UMAP, run on the 256-dimension passage vectors, so passages that mean similar things land near each other. Replaying a question embeds it the same way and lights up its 12 closest passages, the ones that go to Claude with the question. This page holds only dot positions and source types: no text, titles or vectors.
